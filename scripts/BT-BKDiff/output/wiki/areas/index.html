How This Is Calculated

The area guide is generated from BK's levels.txt and monstats.txt. The local data-file guide at docs/Diablo_II_Data_File_Guide/levels.md identifies MonLvl, MonDen, MonUMin, MonUMax, and monster pool columns as the key area spawning fields.

Hell area level uses MonLvlEx(H) when present, then falls back to MonLvl(H). Champions are shown as area level +2 and uniques as area level +3, so top-tier capable means unique monsters can reach level 90 or higher.

Density is the table-derived MonDen(H) value. It is useful as a relative spawn-density signal, not an exact monsters-per-run count. Immunities are inherent monster resistances from monstats.txt where the Hell resistance is at least 100.

Chunk data comes from lvlmaze.txt when a maze row exists, using Hell room count times chunk width and height. Areas without a maze row fall back to levels.txt size columns. This is a rough layout footprint for comparison, not a simulated monster count.

Super chest potential is derived from objects.txt, lvlprest.txt, and DS1 layout files. BK layout overrides are checked first, then the local retail extract at E:\Games\Diablo II Resurrected\Data fills in base game layouts. For randomized outdoor chunks, this means an area can roll a matching preset, not that every map seed guarantees that chest.
