How This Is Calculated

Area levels are Hell difficulty values. Champions spawn at area level +2 and uniques at +3. Density is a relative signal derived from monster spawn weights — higher is denser, but it is not an exact monster count. Map size is estimated from layout data when available. Super chest presence is detected from object and layout files; actual super chest loot depends on the game's treasure class routing.
